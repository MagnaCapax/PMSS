# Cgroup quick reference

This document summarizes useful paths and commands for inspecting per-user cgroups.

## Viewing usage
Run one of the helper scripts:
```
php /scripts/util/showCgroupUsage.php
php /scripts/util/showUserSliceInfo.php
```
The first prints memory and IO usage while the second lists each user's slice configuration alongside current values.

## Adjusting limits
Edit the slice file for a user under `/etc/systemd/system/user-<uid>.slice.d/90-pmss-user.conf` and reload systemd:
```
systemctl daemon-reload
systemctl restart user-<uid>.slice
```

## Important paths
- `/sys/fs/cgroup/user.slice/user-<uid>.slice/memory.current`
- `/sys/fs/cgroup/user.slice/user-<uid>.slice/io.stat`
- `/etc/seedbox/runtime/userConfigs`
- `/var/log/pmss/ioStats/<user>` (per-user IOPS log generated by `userIoStats.php`)

## Systemd helpers
Use `systemctl` to inspect or manipulate a user's slice:
```
systemctl status user-<uid>.slice
systemctl show user-<uid>.slice
systemctl set-property user-<uid>.slice MemoryMax=<value>M
```
After editing slice files by hand remember to run:
```
systemctl daemon-reload
systemctl restart user-<uid>.slice
```
The helper script `showUserSliceInfo.php` prints both the configured limits and
current usage for all users which can be handy when debugging resource issues.
